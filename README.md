# Bond Platform – Phase 1 Prototype

Clickable prototype built from BRD v1.1 for the BRD review discussion. Sample data only.

## Deploy on Render
1. Push this folder (index.html + README.md) to a GitHub repo.
2. Render → New → Static Site → connect the repo.
3. Build command: leave empty. Publish directory: `.`
4. Create Static Site. Render gives you an `onrender.com` link to share.

Note: Render static sites are public — anyone with the link can open it.
